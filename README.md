# CleanTiming ダウンロード

Windows用の入力時刻・画面記録ツールです。このリポジトリでは配布物と説明を公開します。

## ダウンロード

[CleanTiming 1.1.0-beta.1](https://github.com/THRusT555/CleanTiming-downloads/releases/tag/v1.1.0-beta.1)からZIPを取得してください。

ZIP全体を書き込み可能なローカルフォルダーへ展開し、`CleanTiming.exe`を起動します。`runtime`と`documents`を含む構成を保ってください。

## 対応条件

- Windows 11 x64
- SDR・画面回転なしで、D3D11 Desktop Duplicationを使用できる環境
- 解析画面にはMicrosoft Edge WebView2 Runtimeが必要です。.NET Runtimeは同梱しています。

未署名ベータです。アンチチートの公認・ゲームとの互換性・BAN回避は保証しません。

入力を本ツールが受信した時刻とデスクトップ画像を記録し、画像上の変化までの観測区間を調べます。ゲーム内部の処理時刻やサーバーの判定、画面の発光時刻を測るものではありません。

記録はローカルに保存します。共有する際は画像・ログ・メモに私用情報が含まれていないか確認してください。使い方と利用条件はZIP内の文書を参照してください。
