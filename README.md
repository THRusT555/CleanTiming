# CleanTiming

CleanTimingは、マウスのクリックを受信した時刻と、その前後のデスクトップ画像を記録し、**クリックから画面の変化が見えるまでの時間を調べるWindows用ツール**です。

記録後に画像をコマ送り・低速再生して、変化が初めて見えた画像を指定します。ボタンの色変化、メニューの表示、弾数の減少、反動の開始などを対象にでき、設定や条件の異なる2つのセッションをA/B比較できます。

**配布版：1.1.0-beta.1 ／ Windows 11 x64**

## ダウンロード・起動

1. [1.1.0-beta.1のダウンロードページ](https://github.com/THRusT555/CleanTiming-downloads/releases/tag/v1.1.0-beta.1)から、`CleanTiming-1.1.0-beta.1-win-x64.zip`を取得します。
2. ZIP全体を、書き込み可能なローカルフォルダーに展開します。
3. 展開先の`CleanTiming.exe`を起動します。

`runtime`と`documents`を含むフォルダー構成を保ってください。.NET Runtimeは同梱しています。解析画面には、PCにインストールされたMicrosoft Edge WebView2 Runtimeが必要です。

## 主な機能

- **クリックと画像の記録**：クリックの受信時刻と、クリック前後の画像・画像更新時刻を共通の時計で記録します。
- **クリックごとの解析**：画像から画面変化や死亡表示の初確認位置を指定し、観測区間を記録します。メモ・比較ラベル・命中結果も付けられます。
- **画像の再生・コマ送り**：画像時刻に沿った再生、低速再生、1枚ずつの確認、拡大表示に対応します。
- **A/B比較**：2つの記録のクリックやマーカーを基準に時間軸を揃え、画像と確定済みの数値を比較できます。
- **PresentMonによる補助記録**：対象プロセスのPresent提出・OS表示の時刻系列を、取得画像とは別に確認できます。
- **作業の保存・再開**：解析下書きを保存し、観測・作業JSONを書き出して再開できます。診断JSON・時系列CSVも出力できます。

## 記録する

1. 「セッション保存先」と、画像を取得するモニターを選びます。
2. 「開始待ち / 記録秒数」を設定します。初期値は**開始待ち10秒・記録30秒**です。
3. 「クリック前後の画像を保存」を有効にし、必要に応じて画像範囲や形式を設定します。
4. Presentの補助記録を使う場合は、「公式PresentMonを補助記録」を有効にして対象プロセスを選びます。
5. 「記録を開始」または**Alt+F6**を押し、開始待ちの間に対象画面へ切り替えます。
6. 記録中に調べたい操作を行います。設定時間で終了します。途中で終了する場合は「停止」を押します。
7. 画像の保存が終わったら、「QPC画像の解析」を開きます。

開始キーはCtrl+Alt+F6への変更、または無効化ができます。Presentの対象は、記録開始時の前景プロセス、プロセス一覧、PID入力から選択できます。PresentMonが開始できなくても、クリックと画像の基本記録は継続します。

### 画像・保存の設定

| 設定 | 内容 |
|---|---|
| クリック前・クリック後 | それぞれ50〜500ms。初期値は前後各50ms |
| 画像形式 | JPEGまたはPNG。初期値はJPEG・品質75 |
| 取得頻度 | 通常はDXGIの画像更新に追従。上限FPSの指定も可能 |
| 保存方式 | メモリー方式またはストレージ方式。保持画像のRAM上限を設定可能 |
| 保存先 | セッションと一時画像の場所を指定可能 |
| 軽量設定 | 60fps上限・JPEG品質60・Present補助なしへまとめて変更 |

保存する画像範囲を広げるほど、必要なメモリーや容量が増えます。RAM上限は保持画像の設定で、アプリ全体のメモリー使用量の上限ではありません。軽量設定では画像の間隔が広がるため、時間を読み取れる細かさも変わります。

通常の取得はデスクトップ画像の更新に追従する方式です。モニターの表示Hzが取得枚数の固定上限になるわけではなく、ゲームの全描画フレームを取得できる保証もありません。

## クリックから画面変化までを解析する

1. 「QPC画像の解析」で、保存が完了した1回分の記録フォルダーを選びます。
2. 調べるクリックを選び、画像を前後に送って、対象の変化が初めて見える画像を探します。
3. その画像で「画面変化開始」（**F**）を押します。死亡表示も確認する場合は、該当画像で「敵の死亡」（**G**）を押します。
4. 必要に応じて観測対象、比較ラベル、メモ、命中結果を入力します。
5. 「確定して次へ」（**Space**）で保存し、次のクリックへ進みます。測定対象から外すクリックは「除外して次へ」（**X**）で除外できます。

任意イベントのマーカーでは、射撃描画・弾道・命中表示などを別々に指定できます。クリック番号・時刻での検索、未確認・編集中・観測あり・除外済みでの絞り込みにも対応します。

### 主な操作キー

| キー・操作 | 動作 |
|---|---|
| A / D | 前後の画像へ移動。Shift併用で5枚ずつ |
| Q / E | 前後のクリックへ移動 |
| C | クリック受信直前の画像へ移動 |
| F | 現在の画像を画面変化の初確認位置に指定 |
| G | 現在の画像を死亡表示の初確認位置に指定 |
| Space | 確定して次のクリックへ移動 |
| X / U | 除外して次へ / 除外の取り消し |
| R | 指定を解除 |
| V | 次の未確認クリックへ移動 |
| Z | 画像表示を100%へ戻す |
| 画像上のホイール | ポインター位置を中心に拡大・縮小 |
| 拡大中のドラッグ | 表示位置を移動 |
| 画像スライダー上のホイール | 1枚ずつ移動。Shift併用で5枚ずつ |

「画像をコピー」で選択画像をクリップボードへコピーでき、「画像をエクスプローラーで表示」で保存先の画像を選択表示できます。

### 再生と時刻系列

解析画面の「再生」でクリック付近の画像を確認できます。配布版の再生倍率は**0.0001〜4倍の数値入力**です。

再生の基準は、取得画像の時刻、PresentMonの提出時刻、OS表示時刻、均等コマから選択します。画像間では直前の画像を保持し、記録されていない画像を生成・補間することはありません。

Present提出・OS表示・取得画像は独立した系列です。時刻が近くても、同じフレームを表しているとは限りません。

## セッションをA/B比較する

「セッションA/B比較」を開き、次の2通りで比較できます。

### 画像を並べて比較

1. AとBそれぞれの記録フォルダーを選びます。
2. 比較するクリックまたはマーカーを基準イベントとして選び、時刻0を揃えます。
3. 再生・コマ送りで、同じ経過時刻の画像を照合します。各画像範囲の先頭を基準とした、同じ画像番号での照合も選べます。

画像比較だけであれば、観測JSONを作成する必要はありません。

### 確定した観測結果を数値で比較

解析画面で確定した観測結果を使い、条件A・Bの画面変化開始や死亡確認までの平均区間・差を比較できます。観測JSONを複数読み込むこともできます。下書きと除外済みのクリックは集計対象に含みません。

比較結果は「比較JSONを保存」で書き出せます。

## 保存・出力と作業の再開

初期状態では、展開先フォルダー内に次のデータを保存します。

| 場所 | 内容 |
|---|---|
| `sessions` | セッション記録。保存先は変更可能 |
| `data/preferences.json` | 記録・表示などの設定 |
| `data/reviews` | 解析下書き・作業状態 |
| `data/temporary` | 一時画像。保存先は変更可能 |
| `data/webview2` | 解析画面のブラウザープロファイル |
| `data/logs/errors.jsonl` | エラー記録 |

解析画面の「観測・作業JSONを保存」で、確定した観測・マーカー・作業状態を書き出せます。作業を引き継ぐ場合は、元の記録フォルダーを開いて「作業JSONを再開」から読み込みます。

「記録品質・診断を出力」からは、診断JSONと時系列CSVを出力できます。

## 結果の読み方

結果は、**変化がまだ見えない直前の画像と、初めて見えた画像の間の区間**として扱います。たとえばクリック受信から8msの画像に変化がなく、12msの画像で初めて見えた場合、画像から確認できる範囲は8〜12msです。

測定の開始点は本ツールがマウス入力を受信した時刻、画像側の時刻はWindowsが報告するデスクトップ画像の更新時刻です。物理スイッチが入った時刻、ゲーム内部の入力処理、サーバー判定、モニターの走査・発光時刻は測定できません。

小数点以下の表示桁数は測定精度を意味しません。画像間隔が広い箇所は、その分だけ観測できる区間も広がります。グラフの色は同じ記録内での相対的な差を示し、信頼率や正常・異常の判定ではありません。

## 動作環境

- Windows 11 x64
- 既定のD3D11 GPU上でDesktop Duplicationを使用できる、SDR・回転なしのモニター
- 解析用のMicrosoft Edge WebView2 Runtime

HDR、回転画面、別GPU配下のモニター、リモートデスクトップ、記録中の画面構成変更には制限があります。Windows 10・ARMは対象外です。

本体は未署名ベータです。アンチチートの公認は得ておらず、ゲームとの互換性やBAN回避を保証しません。ゲームへの注入、ゲームメモリーの読み取り、入力生成、独自ドライバーは使用しません。

## 起動・記録に問題がある場合

- 起動できない：ZIP全体を展開し、`runtime`を含む構成が保たれているか確認します。
- 解析画面が開かない：WebView2 Runtimeのインストールを確認します。
- 記録が停止する、保存に失敗する：「エラー詳細」のコードと内容を確認します。コード別の対処はZIP内の`documents/SUPPORT.md`にあります。
